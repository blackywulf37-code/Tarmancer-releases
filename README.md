Test Release Patch Notes v0.1.3

    Added treasure chests that can occasionally appear while exploring.
    Chests contain a variety of useful rewards and rare treasures.
    
    Added Mimics—some discoveries may be more dangerous than they first appear.
    
    Mimics feature a unique grabbing attack.
    
    Added new chest artwork, lighting details, opening states, 
    and interaction prompts.
    
    Fixed tether wrapping visuals when different grabbing enemies appear 
    in the same run.



Test Release Patch Notes v0.1.2

    Added the Tar-Assembled, a rare new boss encounter with dangerous anchors, tentacles, 
    unique attacks, and a reassembly phase.
    
    Added unique visual and musical effects for the Tar-Assembled encounter.
    
    Added status-effect icons beside the health bar, making debuffs easier to recognize.
    
    Enemies now leave temporary tarry-green blood splatters when defeated.
    
    Added Calm Nerves, a new passive that rewards briefly standing still.
    
    Repainted several enemy variants with more detailed artwork.
    
    Nests are now rarer and slower, but grant guaranteed talent points when destroyed.
    
    Improved Tar-Assembled balance, attack readability, tether behavior, 
    and horde-spawn protection.
    
    Fixed several combat, movement, and visual issues.
